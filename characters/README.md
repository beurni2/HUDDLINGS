# Characters

One folder per companion, built from its four master sheets (spec section 5b).

| Path | What it holds | Made by |
| --- | --- | --- |
| `reference/` | the 16 master sheets, concept art only; never edited, moved, animated or shipped | the founder |
| `refprep/` | the reference prep: the scripts that crop, cut out, measure, sample and write `model.json` (below) | phase 2 |
| `<species>/refmap/` | the prep's hand-written inputs: every panel's box, the hand-placed landmarks, the swatches' roles and the proposed marking map | phase 2, by hand |
| `<species>/ref/` | crops of every sheet panel, cut-out silhouettes and the measurements behind `model.json`, with an overlay of each to check by eye | `refprep/`, never by hand |
| `<species>/model.json` | the locked model: proportions, landmarks per view, palette, outline widths, marking map | `refprep/`; approved at Gate A |
| `<species>/DECISIONS.md` | every choice where the sheets disagree or say nothing, each with the crop that settled it | phase 2 onward |
| `<species>/src/` | the parts drawn in TypeScript, the rig, clip sources, species parameters | phases 3 to 5 |
| built package | `atlas@2x.png`, `atlas@3x.png`, `atlas@5x.png`, `atlas.json`, `rig.json`, `clips/`, `params.json`, `package.json` (Appendix F) | the build script; never edited by hand |
| `<species>/sounds/`, `<species>/haptics/` | the species' little sounds (AAC) and its Core Haptics patterns (AHAP), named by the clip events that play them | a sound designer or a licensed library for the sounds, with their licences; the agent for the patterns |

The dog comes first (M0). Kitty, bear and rabbit start only after the dog's Gate D for Home and Treats (M2 gate), as parallel lanes.

## The reference prep

`python3 characters/refprep/prepare.py dog` runs every step, in order, from the sheets and `dog/refmap/`:

1. `crop.py`: every panel of the four sheets at its original size, into `ref/panels/`, with `ref/panels.json` and an overlay of the boxes on each sheet. It fails when a drawn item belongs to no panel or label.
2. `measure.py`: the turnaround's cut-out silhouettes, its landmarks per view (eyes, nose, mouth corners, ears, collar, tag, paws, chin, ground), the proportions and the outline's width, in points at the 164 pt height. Each landmark records how it was found; an overlay per view shows them all.
3. `palette.py`: the printed swatches and each region's dominant colour in every view, against the printed values (CIEDE2000), and the blush's level on each cheek.
4. `markings.py`: the proposed marking map, each patch coloured on the panels that show it, with its colour.
5. `model.py`: `model.json`.

Everything in `ref/` and `model.json` is deleted and regenerated byte for byte, so CI and the pre-commit hook rerun it and fail when a committed file is stale, missing or no longer written. The tests (`python3 -m unittest discover -s characters/refprep`) check the colour maths against published values; the crop, the line widths, the head's width, the palette's samplers and the marking patches on drawings with known answers; each step of the cut-out on the point of the dog's sheets it exists for; every automatic landmark on what it names (eyes and nose on their dark blobs, mouth corners on the smile's line, the collar on blue, the tag's top on gold); and that `model.json` is what the scripts write. The colour classes and thresholds are tuned to the dog's sheets; each species' are revisited when its `refmap/` is written (M5), and a view whose landmarks a finder misses fails the run. These tools never ship; the sheets' pixels and anything traced from them never reach the app (rule R8, decision E1).
