# iPhone app

The SwiftUI and SpriteKit app for iOS 17 and newer: the SpriteKit companion runtime, the app, its widget extension and its Notification Service Extension (spec section 18).

- The Xcode project is generated from a text file (XcodeGen), never edited by hand.
- The pure engines (gesture classifier, scene director, energy and trips, souvenir rules) use no Apple framework, so they are tested on Linux too.
- Built, tested and recorded on a GitHub Actions macOS runner; TestFlight builds go to the founder's iPhone.

Starts in section 5b phase 1.
