# Web runtime and Animation Lab

The TypeScript and WebGL character runtime (spec section 5b), shared by the visit page (`web/`) and the Animation Lab in the browser. It reads the same character packages as the SpriteKit runtime and must render the same frames (the parity check in Visual QA).

Built in section 5b phase 1, with a test character made of plain shapes, before any companion art exists.

The Lab's scripts drive the runtime in headless Chromium on SwiftShader, on the deterministic clock:

- `lab/render.ts`: a clip frame by frame, with a contact sheet and an MP4; `lab/render-all.ts` renders every clip of every built package.
- `lab/still.ts`: a named still (a clip that sets the body and head views, at t = 0) for the sheet match: the frame on white and on black, a part-ID pass, and `still.json` to read them by.
- `lab/look.ts`: the drawing loop of phase 3: build the package, render each view's still and run the sheet match, again on every change with `--watch`.

## Stills and the sheet match

The contract between the build, the stills, the sheet match and the look loop (phase 3; spec section 5b, The sheet match):

1. **Model space**: points at the 164 pt height, the origin on the ground under the seat (`model.json`'s origin, the root bone's pivot), x to the viewer's right, y down. Drawings are typed in model space; `characters/draw/frame.ts` wraps each into its bone's space with the runtime's own rest transforms (`src/rig.ts`), so anchors always come from the pivots.
2. **Stills**: `node runtime-web/lab/still.ts --species <s> --still <clip> --ppp <n> --out <dir>` (`npm run still -- …`) loads `build/characters/<s>/`, plays the clip (its views track sets the body and head views, as `still_front` does) at t = 0 on the deterministic clock, and writes into `<dir>`. The folder is replaced whole once every file is written, so a pass that fails leaves the last still as it was. A still Chromium would draw smaller (it silently shrinks a drawing buffer past its limits) fails instead; use fewer pixels per point.
   - `white.png` and `black.png`: the same frame on opaque #FFFFFF and #000000, 8-bit RGBA with no colour chunks, so alpha = 1 − (white − black)/255 and colour = black/alpha.
   - `ids.png`: the same frame with every part in its own flat, opaque ID colour wherever its alpha is at least half its region's own largest alpha, found once from the region's texels: an opaque part from 128 up, as before, and a soft part (the blush at its 0.29 to 0.43 level, a shadow) by its own core, so the sheet match can find it. Clip groups are still clipped by their mask, cut the same way. The background is #000000; a part's ID colour comes from its index in `rig.parts` and is never #000000.
   - `still.json`: `{species, still, clip, views {body, head}, ppp, sizePx [w, h], rootPx [x, y], parts {name: {id "#rrggbb", bone, clipTo?}}, drawn [part names in draw order]}`. Model point (x, y) is at pixel rootPx + ppp·(x, y), where pixel (i, j) covers [i, i + 1) × [j, j + 1).
3. **Source landmarks**: the points the sheet has no finder for (`paw.front.L/R`, `paw.hind.L/R`, `tag.ring`, `seat`). The build writes them to `build/dev/<s>/landmarks.json` as `{view: {name: [x, y]}}` in model space, beside its report and never in `build/characters/`, which the app bundles whole.
4. **Sheet match**: `python3 characters/sheetmatch/match.py <s> --still <dir> --out <dir> [--landmarks <json>]` (`npm run match -- …`; the landmarks default to `build/dev/<s>/landmarks.json`, and a `--landmarks` that is not a file is an error) writes `match.json` (every check with its numbers and its verdict, every threshold it used, paths from the repository's root), `compare.png` (crop | render | outlines and landmarks | onion skin) and `phone.png` (the render at 3x drawn 164 pt tall beside the crop at the same size). It exits 0 when every gating check passes, 1 when one fails, and 2 for any error at all, an import included, leaving no `match.json`. The gating checks are the silhouette's IoU, the alignment, the landmarks, the palette per region, the blush (each cheek's level and colour, and as many cheeks as the sheet's crop shows) and the markings (the right ones, clipped to their parts, and each where the sheet's own patch is: each centroid inside the other's patch grown by 3% of the head's width; a mirrored facing is held to the mirrored patch of its own side's marking). The area ratio, the centroid offset, edge distances, IoU per part and the atlas share are reported, never gating.
5. **Look loop**: `node runtime-web/lab/look.ts <s> <view…> [--watch] [--qa <dir>] [--cache <dir>]` (`npm run look -- dog front`) builds, renders `still_<view>` at 3 px/pt into `build/stills/<s>/<view>/` and runs the match into `qa/phase3/<view>/` (or `<qa>/<view>/`), one line per view. It exits 0 when every view passes, 1 when a check fails and 2 when anything errs. It deletes the old `match.json` before each match, so a crash of the match is reported as a crash, never as the last run's checks.
